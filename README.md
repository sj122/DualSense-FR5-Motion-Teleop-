# PS5 DualSense 实时 RPY 显示

## 项目说明

本项目通过 USB 连接 PS5 DualSense 手柄，读取内置 IMU 传感器（加速度计 + 陀螺仪），使用互补滤波器计算实时的欧拉角（Roll/Pitch/Yaw），并提供两种可视化方式：

1. **曲线绘图** (`Untitled-1.py`）：用 matplotlib 显示 RPY 随时间变化的曲线
2. **3D 立方体** (`cube_3d.py`）：用 vpython 渲染 3D 立方体，根据手柄姿态实时旋转

## 安装依赖

```bash
pip install -r requirements.txt
```

若需要 3D 立方体显示，额外安装：
```bash
pip install vpython
```

## 运行脚本

### 曲线绘图版本

```bash
python Untitled-1.py
```

启动后会自动进行 3 秒校准（手柄请平放并保持稳定）。校准完成后，matplotlib 窗口显示实时 RPY 曲线。

### 3D 立方体版本（推荐）

```bash
python cube_3d.py
```

启动后进行 3 秒校准，然后弹出 vpython 窗口显示一个 3D 立方体。**摇晃手柄，立方体会跟随手柄的姿态旋转**。

## 工作原理

1. **校准阶段**：读取 3 秒的静止状态数据，计算陀螺仪零偏和加速度计基准
2. **传感器融合**：
   - 加速度计：计算 Roll/Pitch（不受积分漂移影响）
   - 陀螺仪：积分计算角速度，并通过自适应零偏估计减少长期漂移
   - 互补滤波：融合两者优势
3. **实时可视化**：
   - 曲线版：matplotlib 绘制 RPY 时间序列
   - 立方体版：vpython 根据欧拉角旋转立方体

## 技术细节

- **Yaw 包装**：为防止 Yaw 无限累积，将其限制在 [-180°, 180°]
- **自适应零偏**：当手柄静止时（加速度 ≈ 1g，陀螺速率 < 10°/s），运行时自动调整陀螺零偏
- **轴映射**：DualSense 陀螺仪的 Pitch/Yaw/Roll 进行了轴交换，以匹配标准坐标系

## 注意事项

- 若图形不显示或数据异常，检查校准打印信息（应显示接近 0 的陀螺零偏和接近 1.0g 的加速度范数）
- Yaw 由纯陀螺积分，长期会有漂移（需磁力计才能完全消除）
- 按 `Ctrl+C` 可随时停止程序

## 可调参数

编辑脚本中的常量可调节：
- `GYRO_SCALE`：陀螺仪缩放因子（默认 1/16.4）
- `GYRO_SCALE_Z`：Z 轴额外缩放（默认 0.1）
- `alpha`：互补滤波系数（默认 0.95，越接近 1 越依赖陀螺）
- `bias_adapt_rate`：自适应零偏更新速率（默认 0.01）
